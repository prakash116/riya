# Riya Closet

A responsive fashion landing page built with Next.js, TypeScript, and Tailwind CSS.

## Live site

https://prakash116.github.io/riya/

## Develop locally

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

Pushing to `main` deploys the static site to GitHub Pages through GitHub Actions.
